Colver Belote Contree Engine

Colver is a high-performance Belote Contree game environment built for reinforcement learning research. The core engine is written in Rust, capable of over 1 million rollouts per second. This web interface lets you play against various AI agents, watch them compete, and analyze positions.

Source code: github.com/Avo-k/colver

Game Modes

Jouer

Play as South against AI opponents. Choose the AI for your opponents (East/West) and your partner (North) independently. The game follows official FFB Belote Contree rules: bidding phase with coinche/surcoinche, then 8 tricks of play. First team to 2000 cumulative points wins the match.

Regarder

Spectate AI vs AI matches with full visibility of all hands. Assign a different agent to each of the 4 seats, then step through actions one by one, play full tricks, or use auto-play. The stats panel shows MCTS visit counts and Q-values for each decision.

Analyse

Set up a custom position by dragging cards from the palette into 4 player drop zones (or use "Donne aleatoire" for a random deal). Configure the contract (trump, value, declaring team), then run IS-MCTS analysis to see the best move and action rankings for the current player.

AI Agents

DouDou Recommended

Deep Monte-Carlo Q-network trained via self-play (DouZero-style). A 3-layer MLP (1024 hidden units, ~2.6M parameters) takes a 415-dimensional observation and outputs Q-values for all 32 cards in a single forward pass — no search tree needed. Bidding uses a hand-tuned heuristic (ImprovedV2). Inference runs in pure Rust at ~1ms per decision.

Smart IS-MCTS Strong

Belief-weighted Information Set Monte Carlo Tree Search. Maintains a probabilistic belief model over hidden cards, updated after every action using hard constraints (void inference, trump ceiling) and soft signals (bidding patterns, play conventions). Samples plausible opponent hands biased by these beliefs, then runs standard MCTS on each world. ~7.5% stronger than Naive IS-MCTS in match play.

Naive IS-MCTS

Ensemble determinization without a belief model. Samples multiple possible worlds (respecting known void constraints only), runs MCTS on each, and aggregates visit counts across all worlds. Simpler than Smart IS-MCTS but still a competent player.

Oracle (MCTS)

Perfect-information MCTS that sees all 4 hands. Uses UCT (UCB1 for trees) with arena-based tree allocation for cache efficiency. Unrealistically strong since it has no hidden information — useful as an upper bound for evaluating other agents' play quality.

Heuristique Watch only

A fast deterministic strategy with no search. Follows a handcrafted decision tree: safe leads, partner feeding, minimum winning card, cheapest trump cut. Runs at ~769K games/sec and is used as the rollout policy inside MCTS agents.

Aleatoire Watch only

Plays uniformly random legal moves. Useful as a baseline for measuring other agents' strength. Runs at ~1.3M rollouts/sec.
